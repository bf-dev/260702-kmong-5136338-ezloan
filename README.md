# 이지론 배너 자동등록 (데스크탑)

Kmong 고객 `5136338` 전용. 네이버 아이디/비밀번호로 **자동 로그인**하여
이지론(ezloan.io) 실시간 문의글에 `더원대부` 배너를 자동 등록하는 Windows 프로그램.

기존 두 저장소(`260615-...-ezloan-banner`, `260702-...-ezloan-desktop`)를 하나로 통합한 버전이며,
쿠키를 매번 붙여넣던 방식을 없애고 **아이디/비밀번호 자동 재로그인**으로 바꿨다.

## 동작 흐름

1. TK 창에 네이버 **아이디 / 비밀번호** 입력 후 [시작].
2. 프로그램 전용 크롬(Chrome for Testing)을 자동 준비(최초 1회 설치, 크롬 미설치 PC도 OK).
3. `ezloan.io/m/login` → "네이버로 로그인" → 아이디/비밀번호 자동 입력(네이버 UI는 한국어 강제).
4. 네이버 **보안문자**가 나오면 고객 PC에 **작은 입력창**(이미지 + 질문 + 정답 입력)이 뜬다.
   고객이 사진을 보고 답을 입력하면 로그인이 이어진다. ([새 문자]로 다른 문제도 받기 가능)
5. 로그인 성공 → 세션 쿠키 확보 → 브라우저 종료 → **순수 HTTP 등록 루프** 시작
   (look-ahead 로 새 글을 즉시 잡아 상위 노출).

## 구성

| 파일 | 역할 |
|------|------|
| `main.py` | 진입점 (Tkinter) |
| `app.py` | GUI: 아이디/비밀번호/시작·정지/로그 |
| `chrome_provisioner.py` | 전용 크롬 자동 설치/캐시 (Win/mac/Linux) |
| `browser.py` | 셀레니움 드라이버 생성(자동화 흔적 제거) |
| `naver_login.py` | 네이버 자동 로그인 + 한국어 강제 + 보안문자 콜백 + 창 복구 |
| `captcha_dialog.py` | 보안문자 입력창(Tkinter, 이미지+질문+정답) |
| `bridge.py` | 원격 진단 로그(works.insu.ng) |
| `ezloan_bot.py` | 배너 등록 루프(목록 폴링 + look-ahead + 등록 + 순위확인) |

## 보안문자 처리

로그인 중 보안문자가 뜨면 고객 PC에 작은 입력창이 뜨고, 고객이 사진을 보고 답을 입력한다.
(워커 스레드가 요청하면 Tk 메인 스레드에서 모달 창을 띄우고, 답이 들어올 때까지 대기한다.)

> 실측: 네이버 아이디 칸에는 `@naver.com` 없이 **순수 아이디**를 넣어야 한다(모듈이 자동 처리).
> 고객 자택 IP 에서는 보안문자가 드물게 나오고, 데이터센터/해외 IP 에서는 자주 나온다.

## 빌드

GitHub Actions `windows-latest` + PyInstaller `--onefile --noconsole`.
`main` 브랜치 push 시 자동 빌드되어 Release `latest` 에 `ezloan-bot-<version>.exe` 로 게시된다.
